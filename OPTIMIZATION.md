# Отчёт по оптимизации

## Медиатека

На странице 5000 строк, и каждая строка рендерится медленно из-за
simulateHeavyRender(). Перед правками я записала профиль в React DevTools:

- первый рендер списка занял **1251 мс**;
- потом страница перерисовывалась каждую секунду из-за таймера, и каждый
  такой рендер занимал **1020–1100 мс**, хотя я ничего не делала;
- когда я выбрала один альбом и строк стало меньше, тот же рендер занимал
  всего **6–9 мс**. Значит, тормозит именно рендер всех 5000 строк.

| Что происходило | До | После |
|---|---|---|
| Первый рендер списка | 1251 мс | 13,6 мс |
| Рендер от таймера (ничего не делаю) | 1020–1100 мс | 0,2 мс (обновляется только TimeOnPage) |

### 1. Рендерились все 5000 строк

**Проблема:** на экране видно примерно 9 строк, а рендерились все 5000.

**Что сделала:** сделала виртуализацию через @tanstack/react-virtual.

**Почему:** теперь рендерятся только те строки, которые видно. Пагинацию
не делала, потому что она меняет вид страницы.

### 2. Таймер

**Проблема:** таймер был в state страницы, и каждую секунду
перерисовывалась вся страница. Рендер длился больше секунды, поэтому
страница лагала постоянно.

**Что сделала:** вынесла таймер в отдельный компонент TimeOnPage.

**Почему:** теперь каждую секунду обновляется только таймер,
а список не трогается.

### 3. Фильтрация и сортировка

**Проблема:** список фильтровался и сортировался заново при любом
рендере, даже при нажатии «В избранное».

**Что сделала:** обернула visiblePhotos в useMemo.

**Почему:** теперь список пересчитывается только когда меняется
поиск, альбом, сортировка или сами фото.

### 4. handleToggleFavorite

**Проблема:** функция создавалась заново при каждом рендере, поэтому
строки получали новый проп.

**Что сделала:** обернула её в useCallback и использовала
setFavorites(prev => ...).

**Почему:** так функция всегда одна и та же, и ей не нужен favorites
в зависимостях.

### 5. Перерисовка всех строк

**Проблема:** при нажатии «В избранное» перерисовывались все строки.

**Что сделала:** обернула PhotoRow в React.memo.

**Почему:** теперь перерисовывается только та строка, которую нажали.
simulateHeavyRender() удалять нельзя, поэтому лучше просто реже
рендерить строки.

## Разделение кода

**Проблема:** код всех страниц был в одном файле.

**Что сделала:** подключила страницы через React.lazy и добавила Suspense
с Loader внутри Layout.

**Почему:** теперь страница загружается, только когда на неё переходишь.
Suspense внутри Layout, поэтому шапка не пропадает. После npm run build
у каждой страницы появился свой файл.
